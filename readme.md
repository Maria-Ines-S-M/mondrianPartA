# Parte A

Para o desenvolvimento da proposta do exercício 1 Parte A, comecei por ver as dimensões do quadro e posteriormente com o Adobe Illustrater através das suas ferramentas consegui observar quais eram as coordenadas de cada linha e forma pertencente ao quadro e os valores das cores. Para criar as linhas do quadro e as formas usei o line() e o rect() que se encontravam exemplos explicativos no site p5.js. Optei aqui por escolher o rect() em vez do square() para não ficar limitada aos lados prefeitos da forma.
